# Student Performance Analysis 📊

A beginner-friendly Python data analysis project that explores student marks, calculates averages, identifies the highest-performing student, and visualizes subject performance.

## Features
- Loads sample student marks from a CSV file
- Calculates total and average marks
- Shows subject-wise average
- Finds the top-performing student
- Creates a bar chart of subject averages

## Tech stack
Python, Pandas, Matplotlib

## Setup
```bash
python -m pip install -r requirements.txt
```

## Run
```bash
python student_analysis.py
```

The chart is saved as `subject_averages.png`.
